# 学计算机的心路
## 致读者
我写下这些文字的时候已经是凌晨4：21，八月的岭南只有在深夜可得片刻的凉意，今天是我学习计算机网络的第9天，这九天都是这样的日夜配着这样的宁静。
这是我的第一篇上传到自己的网站上的博文，也是我开启学习之旅的一个里程碑。也是在这之中我体验到一生中少有的学习的快乐，不寄托于外力的压迫，仅凭热爱就能让我独自学习到深夜。我明白自己的作品也还有很多的不足和可改进之处，我会在这条路上继续努力，同时也希望有更多的小伙伴可以加入这个小小的网站，一起玩一起学。

***愿大家都能找到自己的心之所向！***
