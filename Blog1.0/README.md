# 我的小博客

一个用纯 HTML + CSS + JavaScript 写的简单可交互本地博客网页，不需要安装任何东西，打开就能用。

---

## 一、如何本地运行

### 方法一：
1. 找到 `Blog1.0.html` 文件
2. 双击它，会自动用默认浏览器打开
3. 完成！网页已经在运行了

### 方法二：
1. 右键点击 `Blog1.0.html`
2. 选择"打开方式" → 选一个浏览器（Chrome / Edge 都可以哦~）

### 方法三：
1. 打开浏览器
2. 把 `Blog1.0.html` 文件直接拖到浏览器窗口里

> 小tips：这是纯前端网页，不需要服务器、不需要安装 Node.js、不需要联网，本地直接运行。

---

## 二、HTML、CSS、JS 分别的作用

| 技术 | 在这个项目里做了什么 |
|------|------|---------------------|
| **HTML** |定义了网页有哪些东西：标题、导航栏、搜索框、4篇文章、页脚、按钮 |
| **CSS** |  决定了颜色、字体、大小、间距、圆角、阴影、深色模式、悬停动画等所有外观 |
| **JavaScript** |  实现了4个交互功能：点击文章展开/收起、搜索过滤、深色模式切换、返回顶部 |


---

## 三、这个网页有哪些功能？

1. **文章列表**：4篇博客文章，以卡片形式展示
2. **点击展开/收起**：点任意文章卡片，正文会展开；再点一次收起
3. **搜索功能**：在搜索框输入关键词，文章会实时过滤
4. **深色/浅色模式**：点导航栏的按钮，切换主题
5. **响应式**：手机和电脑上都能正常显示
