第一天学HTML：标签是什么？

2026-08-07 · 标签：HTML

HTML 就像搭积木，每个标签是一块积木。p 是段落，h1 是大标题，img 是图片。

口诀：HTML 管"有什么"，CSS 管"长什么样"，JS 管"能做什么"。

第二天学CSS：给网页化妆

2026-08-08 · 标签：CSS

CSS 是网页的化妆品。颜色、字体、大小、间距全靠它。写法：选择器 { 属性: 值; }

常用选择器：标签名（p）、类名（.btn）、ID（#header）。类名可重复，ID 只能用一次。

第三天学JavaScript：让网页动起来

2026-08-09 · 标签：JavaScript

JS 让网页活过来。点击有反应、输入有提示、不刷新就能更新内容。

三步公式：1.找到元素 2.监听事件 3.改变样式或内容。
